# LiveTrans 디자인 시스템

ui-ux-pro-max(v2.15.0) 검색 결과를 macOS 네이티브 읽기 앱에 맞게 조정한 기준이다.
검색어: `real-time transcription translation productivity tool` (`--design-system`, variance 3 · motion 2 · density 6),
`japanese korean multilingual reading` (typography), `dynamic type dark mode semantic color` (swiftui).

## 스타일 방향 — Minimalism & Swiss Style

- 내용이 주인공인 읽기 화면. 원문 왼쪽, 번역 오른쪽의 2열 격자 하나로 끝낸다.
- 그림자·그라데이션·카드 없음. 구조는 괘선 하나와 여백으로만 나눈다.
- 색은 정보를 나타낼 때만 쓴다: 브랜드 블루(확정·포커스), 호박색(1차 번역), 빨강(녹음 중). 바탕과 글자는 잉크 블루 계열.
- 움직임은 상태가 바뀔 때만 쓴다: 1차 번역 → 보정본 색 전환 0.6초. 녹음 표시등은 깜빡이지 않고 켜져만 있다("듣는 중" 글자가 이미 알려 준다).
- DB가 추천한 랜딩 패턴(제품 데모·스크롤 연출)과 GSAP 모션은 웹 마케팅용이라 쓰지 않는다.

## 컬러 팔레트 — 잉크 블루 앵커

DB `B2B Service` 팔레트(네이비 + 블루)의 방향을 따르되, 값은 Tailwind 기본 색표를 그대로 쓰지 않는다.
hallmark audit(2026-11-09)에서 기본 색표 번호를 그대로 쓴 것이 AI 템플릿 인상의 주원인으로 지적돼,
잉크 블루 앵커(OKLCH 색상각 250°) 하나에서 밝기·채도만 바꿔 다시 만들었다.

| 역할 | 라이트 | 다크 | 쓰임 |
|---|---|---|---|
| Primary (블루) | `#165E98` oklch(47% 0.115 248) | `#6BBAF0` oklch(76% 0.11 240) | 보정본 글자, 버튼 강조·포커스 |
| Background | `#F2F6FB` oklch(97.2% 0.008 250) | `#0E141E` oklch(19% 0.022 258) | 열 머리·하단 상태 줄 바탕 |
| Surface | `#FBFDFF` oklch(99.3% 0.004 250) | `#141C27` oklch(22.5% 0.025 258) | 읽기 영역 바탕 (순백 대신 앵커 쪽으로 살짝 물들임) |
| Foreground (잉크) | `#172232` oklch(25% 0.035 258) | `#DFE5EC` oklch(92% 0.012 250) | 원문 본문 |
| Muted Foreground | `#5F6A77` oklch(52% 0.025 255) | `#969FAB` oklch(70% 0.02 255) | 번역 중, 전사 중, 빈 화면 안내, 보조 문구 |
| Border | `#DAE0E7` oklch(90.5% 0.012 250) | `#2B3340` oklch(32% 0.025 258) | 가운데 괘선, 구분선 |
| Draft (호박) | `#97570D` oklch(52% 0.115 62) | `#EEB154` oklch(80% 0.13 75) | 1차 번역 글자와 점선 밑줄 |
| Destructive | `#C52C2A` oklch(54% 0.19 27) | `#F2716A` oklch(70% 0.16 25) | 녹음 중 표시등과 "듣는 중" |

글자색 대비(읽기 영역 / 열 머리 바탕 기준): 라이트 최저 5.1:1(Muted), 다크 최저 6.0:1(Destructive).

번역 단계: 번역 중 = Muted Foreground("번역 중…" 문구), 1차 번역 = Draft + 점선 밑줄, 보정본 = Primary(밑줄 없음).
색을 구분하지 못해도 문구와 밑줄로 단계를 알 수 있다. 블루와 호박색은 적록 색각 이상에서도 구분되는 짝이다.

## 타이포그래피 — Japanese Elegant (Serif 제목 + Sans 본문)

DB 조합은 Noto Serif JP / Noto Sans JP다. Noto는 macOS에 기본으로 없어서 같은 역할의 시스템 서체로 바꾼다.

| 역할 | 서체 | 크기 |
|---|---|---|
| 제목(열 머리) | 시스템 세리프(New York) → Hiragino Mincho ProN W6 → AppleMyungjo | 13 semibold |
| 원문 본문 | 시스템 산세리프(SF) → Hiragino Sans(일본어) / Apple SD Gothic Neo(한국어) | 15, 행간 +5 |
| 번역 본문 | 같은 산세리프, 한 단계 크게 | 17, 행간 +4 |
| 표시("듣는 중") — `Typography.label` | 같은 산세리프 | 13 medium |
| 보조(상태 줄, 범례) — `Typography.caption` | 같은 산세리프 | 12 |

세리프는 대체 글꼴을 직접 지정한다. 지정하지 않으면 한자는 명조, 가나 일부는 고딕으로 섞인다.
화면 코드는 글꼴 크기를 직접 적지 않고 `Typography` 토큰만 쓴다.

## 레이아웃

- 컨트롤(언어 선택, 원문 복사, 시작/중지)은 창 툴바. 버튼은 아이콘과 글자를 함께 보인다.
- 본문 최대 폭 1080pt, 열 좌우 여백 24pt, 문단 위아래 14pt. 창 최소 폭 760pt.
- 진행 중 문단은 맨 아래, 가운데 괘선 위에 빨간 표시등.
- 시작 전 빈 화면도 같은 2열 첫 줄에 왼쪽 정렬로 "원문이 여기에 / 번역은 이쪽에"를 옅게 적는다. 정중앙 정렬 제목은 쓰지 않는다.
- 언어 이름은 화면 문구에 맞춰 한국어로 보인다.

## 금지

- 보라 그라데이션, 같은 카드 반복, 그림자 장식
- 대비 4.5:1 미만 글자색, 색만으로 상태 전달(범례를 항상 같이 둔다)
- 이모지 아이콘(SF Symbols 사용)
- Tailwind 등 기본 색표 번호를 그대로 쓰는 것, 순백 `#FFFFFF`·순흑 바탕
- 정보가 없는 장식 움직임(깜빡이는 라이브 점 등)
